# מסלול דפ״ר למשטרה

אפליקציית לימוד למבחן המיון הממוחשב של משטרת ישראל (סגנון דפ״ר): **סדרות חשבוניות, סדרות צורניות ומילוי הוראות**.
מבוססת על חוברת התרגול של מחוז ת״א (מעודכנת 01.09.2025) ומרחיבה אותה.

## מה יש באפליקציה
- **תוכנית של 14 יום** — בכל יום שיעור טכניקות ו-3-5 מקבצים (~40-57 שאלות ביום, 688 שאלות בתוכנית).
- **מחוללי שאלות** לכל סוגי השאלות שבחוברת (10 סוגי סדרות, 7 סוגי מטריצות, 11 סוגי מילוי הוראות) — אינסוף שאלות, כל תשובה מחושבת ונבדקת.
- **לימוד אדפטיבי** — לכל נושא רמה 1-5; תשובה נכונה ומהירה מעלה את הקושי, טעות מורידה. אפשר גם לבחור רמה קבועה.
- **רמז** (שני שלבים: כיוון ← פסילת תשובות), **דלג**, **מפת מקבץ** (מה נעשה / מה לא) וחזרה לכל שאלה.
- **הסבר מלא + הדגמה צעד-אחר-צעד** לכל שאלה (קשתות בסדרות, פירוק חוקים במטריצות, ציור מסלול בשאלות מצפן).
- **סימולציות**: מבחן ממוחשב אדפטיבי (שעון לשאלה) ומבחן כיתה (זמן לפרק, קנס ¼ על טעות), עם תחקיר.
- **התקדמות**: חולשות, רמות לפי נושא, מקבץ חולשות אוטומטי, גיבוי והעברה בין מכשירים.
- עובד במחשב ובאייפון/אנדרואיד (אפשר "הוסף למסך הבית"), בעברית מלאה, מצב בהיר/כהה.

## הפעלה
`index.html` הוא קובץ יחיד שמכיל את כל האפליקציה — אפשר לפתוח אותו ישירות בדפדפן במחשב.

### פרסום לכל אחד (GitHub Pages, חינם)
1. למזג את הענף ל-`main`.
2. ב-GitHub: **Settings ← Pages ← Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, תיקייה `/ (root)` ← Save.
3. אחרי דקה-שתיים האפליקציה זמינה בכתובת: `https://yitzhaki173-lab.github.io/Margalit/`
4. באייפון: לפתוח בספארי ← כפתור השיתוף ← "הוסף למסך הבית".

## פיתוח
- קוד המקור ב-`src/`; `python3 build.py` מאחד אותו ל-`index.html` (ול-`dist/artifact.html`).
- `node tests/test-generators.js` — בדיקת עומס לכל המחוללים (כל נושא × כל רמה × מאות זרעים).
- `NODE_PATH=$(npm root -g) node tests/e2e.js` — בדיקת דפדפן מקצה לקצה (Playwright) על כל התוכנית והסימולציות.

> אפליקציית תרגול עצמאית — אינה קשורה רשמית למשטרת ישראל. הציונים בסימולציות הם הערכה לתרגול בלבד.
